Lantern Keeper is a three-lane night-defense arcade game: moths and shadows drift down a rural courtyard toward three lanterns, and a small keeper swats them, catches fireflies, and relights the lamps until dawn.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: the game is plain static files under game/.
